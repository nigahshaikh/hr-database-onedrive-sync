## 🚀 Quick Start

### Step 1: Install Dependencies
```bash
pip install -r test_requirements.txt
```

### Step 2: Start API Server
```bash
python -m uvicorn api:app --reload
```
*Keep this terminal open - API must be running for tests*

### Step 3: Run Tests (New Terminal)

**Option A - Interactive (Recommended for first run)**:
```bash
python test_api_manual.py
```

**Option B - Automated Tests**:
```bash
pytest test_api.py -v -s
```

**Option C - Menu-Based Selection**:
```bash
python run_tests.py
```

## ⚠️ Troubleshooting

**Problem**: Connection refused
- **Solution**: Make sure API is running with `python -m uvicorn api:app --reload`

**Problem**: No employees found
- **Solution**: Check OneDrive connection and data file access

**Problem**: Import errors
- **Solution**: Run `pip install -r test_requirements.txt`

**Problem**: Tests pass but data looks incomplete
- **Solution**: Run manual test to see full data display: `python test_api_manual.py`
