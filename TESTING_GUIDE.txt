"""
Complete Step-by-Step Guide to Running Tests
This file contains all the commands and steps needed
"""

# ============================================================================
# STEP 1: INSTALL DEPENDENCIES
# ============================================================================

# Open PowerShell or Command Prompt and run:
"""
pip install -r test_requirements.txt
"""

# Expected output:
"""
Successfully installed pytest-7.4.3 pytest-asyncio-0.21.1 httpx-0.25.1 
requests-2.31.0 fastapi-0.109.0
"""

# ============================================================================
# STEP 2: START THE API SERVER
# ============================================================================

# In PowerShell, run:
"""
python -m uvicorn api:app --reload
"""

# Expected output:
"""
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Started server process [1234]
INFO:     Application startup complete
"""

# ============================================================================
# STEP 3: VERIFY API IS RUNNING
# ============================================================================

# In a NEW PowerShell window, test connectivity:
"""
curl http://localhost:8000/meta
"""

# ============================================================================
# STEP 4: RUN THE TESTS
# ============================================================================

# Option A: AUTOMATED TESTS (Pytest)
# ═════════════════════════════════════════════════════════════════════════

# Run all tests with verbose output:
"""
pytest test_api.py -v -s
"""

# Run a specific test class:
"""
pytest test_api.py::TestSearchEmployees -v -s
"""

# Run with coverage report:
"""
pytest test_api.py -v --cov=api --cov-report=html
"""

# Run quick smoke tests:
"""
pytest test_api.py::TestMetadataAndHealth -v -s
pytest test_api.py::TestDataPresence -v -s
"""

# Option B: INTERACTIVE MANUAL TESTS (Recommended for first run)
# ═════════════════════════════════════════════════════════════════════════

# Run interactive tests:
"""
python test_api_manual.py
"""

# This will display:
# - API connection status
# - Metadata from server
# - Sample employee data
# - Department statistics
# - Nationality breakdown
# - Exited employee records
# - Database summary

# Option C: QUICK TEST RUNNER (Menu-based)
# ═════════════════════════════════════════════════════════════════════════

# Run the interactive menu:
"""
python run_tests.py
"""

# Then select from the menu:
# 1. All pytest tests
# 2. Pytest with coverage
# 4. Interactive manual tests
# 5. Quick smoke test
# etc.

# ============================================================================
# WHAT TO DO IF TESTS FAIL
# ============================================================================

"""
Problem: Connection refused (API not running)
Solution: 
  1. Make sure you ran: python -m uvicorn api:app --reload
  2. Check that it shows "Uvicorn running on http://127.0.0.1:8000"

Problem: No employees found
Solution:
  1. Check OneDrive connection
  2. Verify HR_Database.py file is accessible
  3. Run refresh manually: POST to /action/refreshData

Problem: Import errors
Solution:
  1. Install dependencies: pip install -r test_requirements.txt
  2. Verify hr_master_module.py exists

Problem: Module not found - hr_master_module
Solution:
  Check that:
  - File is named HR_Database.py (exact spelling)
  - File is in the same directory as api.py
  - Or create an alias: ln -s HR_Database.py hr_master_module.py
"""
